# FirstTouchIQ Assistant Coach Implementation Plan

- Support four or more assistant coaches, each with their own account.
- Administrator approval is required before a new coach gets access.
- Only the administrator can approve coach, parent, and player registrations.
- Approved assistants can access both the 11U Girls and 12U Girls teams.
- Assistants can create and publish their own assignments, and view players, answers, and progress for both teams.
- Assistants can edit or delete only their own assignments.
- The administrator can manage all assignments.
- Preserve existing parent accounts, registration, and assignment workflows.

Implementation must include database-level permission checks, not just hidden buttons.

This document is a plan only. No database migration or production deployment is authorized by committing it.
